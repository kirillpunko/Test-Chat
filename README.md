# Инструкция по запуску

### 1. Клонирование репозитория
```bash
git clone https://github.com/kirillpunko/Test-Chat.git
cd Test-Chat
```

### 2. Установка зависимостей
```bash
npm install
```

### 3. Запуск проекта в режиме разработки
```bash
npm run dev
```

После этого приложение откроется по адресу: **http://localhost:5173**
